# Scratch starter project

To get started:

- Run `npm i` to install dependencies
- Run `npm start` and open http://localhost:3000 to see the app

## Block Studio (assignment solution)

Scratch-style visual editor built in `src/studio` (React + Tailwind, JavaScript).

- Motion: move, turn, go to. Looks: say, think. Control: repeat animation.
- Drag and drop blocks from the palette into a sprite's script; drag back to delete.
- Multiple sprites, each with its own script. "Play all" runs every sprite.
- Hero feature: when two sprites collide, their animations swap.
  Click "Load collision demo", then "Play all" to see the example from the brief.

Run: `npm i`, then `npm start`, and open http://localhost:3000.
